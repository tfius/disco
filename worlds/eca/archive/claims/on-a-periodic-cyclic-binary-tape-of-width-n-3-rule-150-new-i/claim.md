On a periodic (cyclic) binary tape of width N ≥ 3, Rule 150 (new_i = old_{i-1} XOR old_i XOR old_{i+1}) is a linear map over GF(2): step(s XOR t) == step(s) XOR step(t) for all states s,t, and step(0)==0. Its global map is singular (has a nontrivial kernel, i.e. is not a bijection) if and only if N is divisible by 3; whenever singular the kernel has dimension exactly 2 (never more, never less), and for all N not divisible by 3 the map is bijective (trivial kernel). Verified exhaustively via GF(2) Gaussian elimination on the circulant coefficient matrix for all N in range(3, 101).

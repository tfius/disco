On a periodic (cyclic) binary tape of width N ≥ 3, Rule 90 (new_i = old_{i-1} XOR old_{i+1}) is a linear map over GF(2) whose transition matrix is the circulant with 1s at offsets ±1; its kernel dimension depends only on the parity of N, not on any other factor of N (verified exactly for N=3..64, including primes and powers of 2): kernel dimension = 1 when N is odd, 2 when N is even. Equivalently the map has exactly 2^(N-1) distinct output states for odd N and 2^(N-2) for even N — never bijective for N≥3.

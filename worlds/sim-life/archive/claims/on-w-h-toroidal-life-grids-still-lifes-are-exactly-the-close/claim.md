On W×H toroidal Life grids, still lifes are exactly the closed walks of the row-pair transfer graph: with states (a,p) ∈ {0..2^W−1}² and an edge (a,p)→(p,b) iff the Life rule fixes every cell of row p given row a above and row b below, the number of still lifes on the W×H torus equals the number of closed walks of length H (trace(M^H)), verified against brute-force enumeration for all (W,H) ∈ {3,4}×{2,3,4} (counts 3,127,39 / 9,39,53). The growth rate λ_W (spectral radius of M) is governed by the SCC structure, which changes qualitatively at W=3 vs W≥4: for W=3 the graph has exactly two nontrivial SCCs — a 27-state SCC of period 3 with spectral radius exactly 3 which does NOT contain the empty state (it is the all-rows-alive/dead "binary" family: rows in {000,111} patterns cycling with period 3), and a 30-state aperiodic SCC containing the empty state with radius μ ≈ 2.7036318 — so N(3,H) oscillates with period 3 in H (e.g. N(3,2..7) = 3,127,39,121,2595,1177) and the correction d(H) = N(3,H) − 3·3^H for 3|H grows like μ^H (d(H+3)/d(H) → μ³ ≈ 19.76). For W = 4,5,6,7 there is exactly ONE nontrivial SCC; it is aperiodic (period 1) and contains the empty state, with radii λ_4 ≈ 2.5537154, λ_5 ≈ 4.4791774, λ_6 ≈ 5.0930358, λ_7 ≈ 6.4166263. Consequently the per-cell growth η_W = λ_W^(1/W) is NOT monotone in W: η_3 ≈ 1.4422 > η_5 ≈ 1.3497 > η_8 ≈ 1.3186 > η_6 ≈ 1.3117 > η_9 ≈ 1.3076 > η_7 ≈ 1.3042 > η_4 ≈ 1.2641, with the W=3 value inflated by the period-3 binary-state SCC rather than by generic still-life richness.

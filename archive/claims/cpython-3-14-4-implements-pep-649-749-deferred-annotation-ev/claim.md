CPython 3.14.4 implements PEP 649/749 deferred annotation evaluation: `def f(x: Undef)` compiles without evaluating annotations, storing a callable `f.__annotate__` instead. Accessing `f.__annotations__` triggers evaluation at access time — raising `NameError` if a name is still unbound, and that failure does not poison anything: the same access succeeds later once the name is bound. The first *successful* evaluation is cached in `__annotations__`, so subsequently rebinding the name does not change the already-materialized dict. The stdlib `annotationlib.Format` enum has exactly four members (VALUE=1, VALUE_WITH_FAKE_GLOBALS=2, FORWARDREF=3, STRING=4); `get_annotations(..., FORWARDREF)` returns `ForwardRef` objects (carrying an `owner`) for unresolvable names without raising, and `STRING` format returns the annotation source text as plain `str`. Class-body self-references (`x: C` inside `class C`) are legal and resolve to the class object on later access.
